# Development history

This directory preserves repository migration records, historical checkpoints, and release-baseline evidence.

## Registries

- `branch-history.csv` — remote branch snapshot.
- `checkpoint-history.csv` — tag and checkpoint snapshot.
- `script-path-migration.csv` — script/tool path changes.
- `release-baseline.md` — accepted release baseline.

## Archived records

Historical architecture and output-quality checkpoints are retained under `architecture-checkpoints/`.
